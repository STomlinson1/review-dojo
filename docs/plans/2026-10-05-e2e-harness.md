# End-to-end test harness (TOM-41) implementation plan

**Goal:** One command launches the real built Review Dojo with a stand-in at every process boundary and drives
every user-visible flow through the window; the same launcher lets an agent drive the app one shell command at a
time.

**Architecture:** A launcher (`e2e/harness`) prepares a per-run directory and an environment that swaps GitHub
(scripted fake `gh`), git remotes (local bare repositories), both model APIs (one local mock that is also the
proxy tripwire) and two main-process side effects (focus, `shell.openExternal`). Playwright's test runner drives
the built app through `_electron.launch` (`e2e/specs`), with one fixture that gives each test its own run
directory and fails it when any stand-in saw something unscripted. A small CLI (`e2e/harness/cli.ts`) starts the
same launcher detached with a debugging port for agent-driven verification. Nothing in `src/` branches on being
under test; the only app change is accessible names.

**Tech stack:** Electron 44.4.5, electron-vite 5.0.0, React 19, TypeScript ~6.0.3, `@playwright/test` 1.63.0
(new dev dependency, exact version, no browser download needed), `tsx` ^4.23.15 (already present), Node 22.6+
(the fake `gh` runs as TypeScript through Node's type stripping), git, macOS.

## Global Constraints

Every task implicitly includes these. They are the spec's project-wide requirements.

- The suite runs against the built app only, never the dev server. The build runs once before the suite.
- No test-only branch in the app. Stand-ins are supplied through the environment and a per-run user data
  directory.
- Every test gets its own run directory holding user data, `HOME`, `TMPDIR`, the Claude and Codex config
  directories, the fake `gh` log, the mock's log, and the opened-links log. Nothing is shared between tests
  except read-only fixtures.
- GitHub: a scripted fake `gh` first on `PATH` that replays fixtures keyed on its arguments, records every call
  (arguments, stdin, exit code), and exits non-zero on anything unscripted. `SHELL` points at a stub so login-shell
  `PATH` adoption cannot put the real `gh` ahead of the fake.
- Git: real `git`, `https://github.com/` redirected to local bare fixture repositories, `GIT_CONFIG_GLOBAL=/dev/null`
  and `GIT_CONFIG_NOSYSTEM=1`.
- Model providers: the real bundled `claude` and `codex` binaries against one local mock HTTP API (Anthropic
  Messages SSE and OpenAI Responses SSE), scripted per test as an ordered queue of turns.
- Settings are seeded with API-key auth for both providers; dummy keys come from the environment
  (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`). The keychain is not involved.
- Codex's config file sets `analytics.enabled = false`; features `plugins`, `remote_plugin`, `plugin_sharing`,
  `apps` all `false`; and a custom model provider with `supports_websockets = false`. Claude runs with
  `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`.
- Network tripwire: the mock is also the HTTP(S) proxy and rejects and records any non-loopback connection. After
  every test the harness fails the test if the mock saw an unexpected request, has unconsumed scripted turns, or
  the fake `gh` saw an unscripted call.
- The mock answers an unexpected request with HTTP 400 (not 5xx or 429, which the CLIs retry).
- Mock turns are matched by provider and by a substring of the last user-authored or tool-output item, never by
  whole-body equality.
- UI flows run with Claude. Codex gets the subset: tour generation (no streamed previews), a tool step, ask with
  session resume, the repair retry, and cancel.
- Assertions encode what the user is promised: the text on screen after the flow settles, and the exact payload
  that reached `gh`. Intermediate streaming states are asserted only where the mock holds the stream open on
  purpose.
- Determinism: no assertion on relative-time text, elapsed clocks, random ids or OS focus; fixtures with dates
  are generated relative to now.
- The suite does not re-assert what the 17 unit test files already pin (diff parsing, tour normalization, draft
  validity, comment-target mapping, path confinement, JSON repair).
- End-to-end specs are not collected by `npm test`; harness code is covered by `npm run typecheck`.
- Out of scope: the packaged app, Linux, CI, video, screenshot comparison, the Settings "Save key" flow (known
  gap: keys are covered through the environment fallback only), checking fixtures against live GitHub or live
  model APIs, splitting the renderer store (TOM-42).
- Comments in new code state a constraint the code cannot express, or they are not written. No banners, no
  narration.
- Never contact GitHub or a model provider while working on this plan. Every app launch goes through the
  launcher.

## Seams

- One seam: the whole app from the outside. Input is user action in the window; output is the text on screen
  plus what the fake `gh` log, the mock API's request list and the opened-links log recorded.
- Why: the defects this suite exists for live in the joins unit tests cannot reach (IPC wiring, task/cancel/
  progress lifecycle, persistence across relaunch, provider option mapping and stream handling, the diff's
  selection-to-draft path).
- Reused seams: none of the 17 unit test files change. The harness imports only types from `src/shared`.
- Nothing is tested below this seam. `e2e/harness` has no tests of its own; every spec exercises it.

## Decisions

| Decision | Choice | Reason |
|---|---|---|
| Directory layout | `e2e/harness` (launcher and stand-ins, no Playwright test imports except the CLI), `e2e/support` (the Playwright fixture and page helpers), `e2e/specs` (specs), `e2e/.artifacts` (git-ignored build output: fixture repositories, manifest, per-test run directories) | Stand-ins are shared by the suite and the agent CLI; page helpers are shared by specs and the CLI's `step`; keeping them apart keeps the import direction one-way (specs → support → harness) |
| Spec file name | `*.e2e.ts`, matched by `testMatch: '**/*.e2e.ts'` | Vitest's default glob collects `*.test.*` and `*.spec.*` only, so no Vitest config is needed. Dry run: `npx vitest run` still reports `Test Files 17 passed (17)` with the specs present |
| Language | TypeScript everywhere; the two Electron preloads are `.cjs` with `checkJs`; the two files under `bin/` are two-line `sh` shims | Electron's `-r` needs CommonJS; the repo is `"type": "module"`. A new `tsconfig.e2e.json` joins `npm run typecheck`. Dry run: the typecheck caught a real error in `open-links.cjs` |
| Fake `gh` interpreter | `bin/gh` execs the runner's own Node (`DOJO_E2E_NODE`) on `gh-fake.ts` with `--experimental-strip-types` | A `#!/usr/bin/env node` script fails inside the app (no `node` on its `PATH`), and an extension-less CommonJS file breaks under `"type": "module"` (both observed in the spikes). `gh-fake.ts` therefore uses only erasable TypeScript and no local imports |
| Fixtures: git | Built by code (`e2e/harness/remotes.ts`) in Playwright's global setup into `e2e/.artifacts/remotes`, with fixed author and committer dates | Reviewable as source, rebuilt on every run, no binary blobs in the repository |
| Fixtures: `gh` replies | Builder functions in `e2e/harness/world.ts`; dates are computed relative to now | Typed, one place per reply shape |
| Fixtures: tour JSON | Builder in `e2e/harness/tour.ts`, typed from `src/shared/types` | A change to the tour shape becomes a compile error in the fixture |
| Per-test `gh` scripting | `dojo.gh.set(route, ...replies)`. The fake derives a route key from its exact argument shape (`pr acme/widget#7`, `submit acme/widget#7`, `review-comments acme/widget page 1`, …); the nth call to a route gets the nth reply and the last one repeats; an argument shape with no route, or a route with no reply, is unscripted | Tests read as "what GitHub says", and a changed argument shape stops matching and fails the test |
| Per-test mock scripting | `dojo.mock.script(...turns)`, a FIFO of `{ provider, expect, text \| tool, chunks?, delayMs?, hold? }`; `dojo.mock.release(rest?)` finishes held replies | One conversation runs one turn at a time, so a queue is enough; `hold` + `release` is the only way a test asserts a mid-stream state |
| SHAs and hunk ids in scripted tours | Global setup writes `e2e/.artifacts/manifest.json`: for each fixture pull request its SHAs, line counts and `hunks: { path: ['H1', …] }`, numbered by reading `git diff` in order. The fixture hands it to tests as `dojo.prs`; `widgetTour(pr)` reads hunk ids from it | Nothing is hard-coded, and the numbering is derived from git, not from the app's parser |
| Workers | 4, `fullyParallel`, one app launch per test, `retries: 0` | Dry run: 47 tests in 53 s on 4 workers with zero cross-test state; retries would hide the flakiness this suite must not have |
| Tours in non-tour specs | Generated through the UI with one scripted turn (`generateTour`), never seeded on disk | Costs about a second and keeps the suite off the app's storage format |
| Gutter "+" | Stays unnamed; `e2e/support/diff.ts` is the single place that knows the shadow-DOM selectors | The library's `renderGutterUtility` would give a named button, but it throws when combined with `onGutterUtilityClick` (observed: `Cannot use both 'onGutterUtilityClick' and 'renderGutterUtility'`), which the app uses for click and drag |
| System clipboard | The copy test replaces `navigator.clipboard.writeText` in the page | The window is deliberately unfocused, where the real call rejects, and the real clipboard is machine-global |
| Shared modules | Each shared module is delivered whole by the task that creates it, including the few members a later task is first to use | Tasks run strictly in order and never edit an earlier task's module, so interfaces cannot drift |

## Proving a test can fail

The suite pins behaviour the app already has, so a new spec passes on first run. Each task therefore ends with a
named one-line mutation of the app, the tests expected to fail under it, and a revert. Put the failing output in
your task report. A test that does not fail under its mutation is a plan defect: stop and report it.

```ts
import { existsSync, readFileSync, writeFileSync } from 'node:fs'

export interface GhReply {
  stdout?: string
  stderr?: string
  exit?: number
  delayMs?: number
}

export interface GhCall {
  route: string | null
  argv: string[]
  stdin: string
  exit: number
  unscripted: boolean
}

export const json = (value: unknown): GhReply => ({ stdout: JSON.stringify(value) })

export const failure = (stderr: string): GhReply => ({ exit: 1, stderr })

export class Gh {
  private readonly script: Record<string, { from: number; replies: GhReply[] }>

  /** Continues the script already at `scriptPath`, so a second process can add to a running app's replies. */
  constructor(
    readonly scriptPath: string,
    readonly logPath: string,
  ) {
    this.script = existsSync(scriptPath) ? JSON.parse(readFileSync(scriptPath, 'utf8')) : {}
    this.write()
  }

  /** The first reply answers the next call to `route`, the second the one after; the last one repeats. */
  set(route: string, ...replies: GhReply[]): void {
    this.script[route] = { from: this.calls(route).length, replies }
    this.write()
  }

  calls(route?: string): GhCall[] {
    if (!existsSync(this.logPath)) return []
    const calls = readFileSync(this.logPath, 'utf8')
      .split('\n')
      .filter(Boolean)
      .map((line) => JSON.parse(line) as GhCall)
    return route === undefined ? calls : calls.filter((call) => call.route === route)
  }

  unscripted(): GhCall[] {
    return this.calls().filter((call) => call.unscripted)
  }

  private write(): void {
    writeFileSync(this.scriptPath, JSON.stringify(this.script, null, 2))
  }
}
```

```ts
import { appendFileSync } from 'node:fs'
import http, { type IncomingMessage, type ServerResponse } from 'node:http'
import type { AddressInfo, Socket } from 'node:net'

export type ProviderRoute = 'claude' | 'codex'

interface TurnBase {
  provider: ProviderRoute
  /** Must appear in the last user-authored or tool-output item of the request. */
  expect: string
  /** Leaves the stream open after the scripted content until `release()`, so a test can act mid-reply. */
  hold?: boolean
}

export interface TextTurn extends TurnBase {
  text: string
  chunks?: number
  delayMs?: number
}

export interface ToolTurn extends TurnBase {
  tool: { name: string; input: Record<string, unknown> }
}

export type Turn = TextTurn | ToolTurn

export interface MockRequest {
  method: string
  url: string
  route: ProviderRoute | null
  headers: http.IncomingHttpHeaders
  body: Record<string, unknown> | null
  input: string
  closed: boolean
}

export interface Mock {
  url: string
  requests: MockRequest[]
  /** Requests the mock could not match to the next scripted turn, each with the reason. */
  unexpected: string[]
  /** `host:port` of every connection a process tried to make through the proxy. */
  blocked: string[]
  script(...turns: Turn[]): void
  pending(): number
  /** Finishes every held reply, after appending `rest` to its text. */
  release(rest?: string): void
  close(): Promise<void>
}

const sleep = (ms: number) => new Promise((resolve) => setTimeout(resolve, ms))

function pieces(text: string, count: number): string[] {
  const size = Math.ceil(text.length / count)
  return Array.from({ length: count }, (_, index) => text.slice(index * size, (index + 1) * size)).filter(Boolean)
}

function sse(response: ServerResponse): (event: string, data: Record<string, unknown>) => void {
  response.writeHead(200, { 'content-type': 'text/event-stream' })
  return (event, data) => response.write(`event: ${event}\ndata: ${JSON.stringify({ type: event, ...data })}\n\n`)
}

function lastInput(route: ProviderRoute, body: Record<string, unknown>): string {
  const items = ((route === 'claude' ? body.messages : body.input) ?? []) as Record<string, unknown>[]
  // The Claude CLI appends a role:"system" environment message after the real user turn.
  const authored = items.filter((item) => item.role === 'user' || String(item.type ?? '').endsWith('_output'))
  const last = authored.at(-1)
  return last ? JSON.stringify(last.content ?? last.output ?? last) : ''
}

type Finish = (rest: string) => void

async function claudeReply(
  response: ServerResponse,
  body: Record<string, unknown>,
  turn: Turn,
  index: number,
): Promise<Finish | null> {
  const send = sse(response)
  send('message_start', {
    message: {
      id: `msg_${index}`,
      type: 'message',
      role: 'assistant',
      model: body.model,
      content: [],
      stop_reason: null,
      stop_sequence: null,
      usage: { input_tokens: 11, output_tokens: 0 },
    },
  })
  if ('tool' in turn) {
    send('content_block_start', {
      index: 0,
      content_block: { type: 'tool_use', id: `toolu_${index}`, name: turn.tool.name, input: {} },
    })
    send('content_block_delta', {
      index: 0,
      delta: { type: 'input_json_delta', partial_json: JSON.stringify(turn.tool.input) },
    })
  } else {
    send('content_block_start', { index: 0, content_block: { type: 'text', text: '' } })
    for (const piece of pieces(turn.text, turn.chunks ?? 1)) {
      send('content_block_delta', { index: 0, delta: { type: 'text_delta', text: piece } })
      if (turn.delayMs) await sleep(turn.delayMs)
    }
  }
  const finish: Finish = (rest) => {
    if (rest) send('content_block_delta', { index: 0, delta: { type: 'text_delta', text: rest } })
    send('content_block_stop', { index: 0 })
    send('message_delta', {
      delta: { stop_reason: 'tool' in turn ? 'tool_use' : 'end_turn', stop_sequence: null },
      usage: { output_tokens: 7 },
    })
    send('message_stop', {})
    response.end()
  }
  if (turn.hold) return finish
  finish('')
  return null
}

async function codexReply(
  response: ServerResponse,
  _body: Record<string, unknown>,
  turn: Turn,
  index: number,
): Promise<Finish | null> {
  const send = sse(response)
  const created = { id: `resp_${index}`, object: 'response', status: 'in_progress', output: [] }
  send('response.created', { response: created })
  let item: Record<string, unknown>
  let message: { type: string; text: string; annotations: never[] } | null = null
  if ('tool' in turn) {
    item = {
      id: `fc_${index}`,
      type: 'function_call',
      status: 'completed',
      call_id: `call_${index}`,
      name: turn.tool.name,
      arguments: JSON.stringify(turn.tool.input),
    }
    send('response.output_item.added', { output_index: 0, item: { ...item, status: 'in_progress', arguments: '' } })
  } else {
    message = { type: 'output_text', text: turn.text, annotations: [] }
    item = { id: `msg_${index}`, type: 'message', role: 'assistant', status: 'completed', content: [message] }
    send('response.output_item.added', { output_index: 0, item: { ...item, status: 'in_progress', content: [] } })
    for (const piece of pieces(turn.text, turn.chunks ?? 1)) {
      send('response.output_text.delta', { item_id: item.id, output_index: 0, content_index: 0, delta: piece })
      if (turn.delayMs) await sleep(turn.delayMs)
    }
  }
  const finish: Finish = (rest) => {
    if (rest && message) {
      message.text += rest
      send('response.output_text.delta', { item_id: item.id, output_index: 0, content_index: 0, delta: rest })
    }
    send('response.output_item.done', { output_index: 0, item })
    send('response.completed', {
      response: {
        ...created,
        status: 'completed',
        output: [item],
        usage: {
          input_tokens: 11,
          input_tokens_details: { cached_tokens: 0 },
          output_tokens: 7,
          output_tokens_details: { reasoning_tokens: 0 },
          total_tokens: 18,
        },
      },
    })
    response.end()
  }
  if (turn.hold) return finish
  finish('')
  return null
}

  { route: 'claude', path: /^\/v1\/messages(\?|$)/, reply: claudeReply },
  { route: 'codex', path: /^\/v1\/responses(\?|$)/, reply: codexReply },
]

function readBody(request: IncomingMessage): Promise<string> {
  return new Promise((resolve) => {
    let raw = ''
    request.on('data', (chunk) => (raw += chunk))
    request.on('end', () => resolve(raw))
  })
}

export async function startMock(logPath: string): Promise<Mock> {
  const queue: Turn[] = []
  const requests: MockRequest[] = []
  const unexpected: string[] = []
  const blocked: string[] = []
  const sockets = new Set<Socket>()
  const held: Finish[] = []
  let served = 0

  const log = (entry: Record<string, unknown>) => appendFileSync(logPath, `${JSON.stringify(entry)}\n`)

  // 400 makes both CLIs give up at once; they retry 5xx and 429 with backoff.
  const reject = (response: ServerResponse, status: number, why: string) => {
    unexpected.push(why)
    log({ unexpected: why })
    response.writeHead(status, { 'content-type': 'application/json' })
    response.end(JSON.stringify({ type: 'error', error: { type: 'invalid_request_error', message: `mock: ${why}` } }))
  }

  const server = http.createServer(async (request, response) => {
    const raw = await readBody(request)
    const method = request.method ?? ''
    const url = request.url ?? ''
    if (/^https?:\/\//.test(url)) {
      const target = new URL(url).host
      blocked.push(target)
      log({ blocked: target })
      response.writeHead(403).end()
      return
    }
    if (method === 'HEAD' && url === '/api/hello') {
      response.writeHead(200).end()
      return
    }
    const hit = method === 'POST' ? ROUTES.find((candidate) => candidate.path.test(url)) : undefined
    if (!hit) return reject(response, 404, `unknown route ${method} ${url}`)
    const body = JSON.parse(raw) as Record<string, unknown>
    const entry: MockRequest = {
      method,
      url,
      route: hit.route,
      headers: request.headers,
      body,
      input: lastInput(hit.route, body),
      closed: false,
    }
    requests.push(entry)
    response.on('close', () => (entry.closed = true))
    const turn = queue.shift()
    if (!turn)
      return reject(response, 400, `no scripted turn left for a ${hit.route} request: ${entry.input.slice(0, 200)}`)
    if (turn.provider !== hit.route) {
      return reject(response, 400, `next turn is for ${turn.provider} but ${hit.route} called`)
    }
    if (!entry.input.includes(turn.expect)) {
      return reject(
        response,
        400,
        `expected input containing ${JSON.stringify(turn.expect)}, got: ${entry.input.slice(0, 200)}`,
      )
    }
    log({ served: hit.route, expect: turn.expect })
    const finish = await hit.reply(response, body, turn, (served += 1))
    if (finish) held.push(finish)
  })

  server.on('connection', (socket) => {
    sockets.add(socket)
    socket.on('close', () => sockets.delete(socket))
  })
  server.on('upgrade', (request, socket) => {
    unexpected.push(`websocket upgrade ${request.url}`)
    log({ unexpected: `websocket upgrade ${request.url}` })
    socket.end('HTTP/1.1 404 Not Found\r\n\r\n')
  })
  server.on('connect', (request, socket) => {
    blocked.push(request.url ?? '')
    log({ blocked: request.url })
    socket.end('HTTP/1.1 403 Forbidden\r\n\r\n')
  })

  await new Promise<void>((resolve) => server.listen(0, '127.0.0.1', resolve))
  const { port } = server.address() as AddressInfo

  return {
    url: `http://127.0.0.1:${port}`,
    requests,
    unexpected,
    blocked,
    script: (...turns) => void queue.push(...turns),
    pending: () => queue.length,
    release: (rest = '') => {
      for (const finish of held.splice(0)) finish(rest)
    },
    close: () => {
      for (const socket of sockets) socket.destroy()
      return new Promise((resolve) => server.close(() => resolve()))
    },
  }
}
```

```ts
function git(cwd: string, ...args: string[]): string {
  return execFileSync('git', args, { cwd, env: GIT_ENV, encoding: 'utf8' }).trim()
}

function commit(work: string, message: string, files: Record<string, string>): string {
  for (const [path, contents] of Object.entries(files)) {
    mkdirSync(dirname(join(work, path)), { recursive: true })
    writeFileSync(join(work, path), contents)
  }
  git(work, 'add', '-A')
  git(work, 'commit', '--quiet', '-m', message)
  return git(work, 'rev-parse', 'HEAD')
}

function describe(
  work: string,
  pr: Pick<FixturePr, 'number' | 'title' | 'body' | 'baseRefName' | 'headRefName' | 'baseSha' | 'headSha'>,
): FixturePr {
  const mergeBase = git(work, 'merge-base', pr.baseSha, pr.headSha)
  const hunks: Record<string, string[]> = {}
  let path = ''
  let count = 0
  for (const line of git(work, 'diff', '--no-color', '--no-ext-diff', mergeBase, pr.headSha).split('\n')) {
    if (line.startsWith('diff --git ')) path = line.slice(line.indexOf(' b/') + 3)
    else if (line.startsWith('@@ ')) (hunks[path] ??= []).push(`H${(count += 1)}`)
  }
  const stats = git(work, 'diff', '--numstat', mergeBase, pr.headSha)
    .split('\n')
    .map((line) => line.split('\t').map(Number))
  return {
    owner: 'acme',
    repo: 'widget',
    url: `https://github.com/acme/widget/pull/${pr.number}`,
    ...pr,
    additions: stats.reduce((total, [added]) => total + added, 0),
    deletions: stats.reduce((total, [, deleted]) => total + deleted, 0),
    changedFiles: stats.length,
    hunks,
  }
}
```

```ts
import type { Gh } from './gh'
import { failure, json } from './gh'
import type { FixturePr } from './remotes'

export const REVIEWER = 'octo-reviewer'

export const slug = (pr: FixturePr) => `${pr.owner}/${pr.repo}`
export const key = (pr: FixturePr) => `${slug(pr)}#${pr.number}`

export interface ThreadFixture {
  id: string
  path: string
  line: number | null
  startLine?: number | null
  diffSide?: 'LEFT' | 'RIGHT'
  isResolved?: boolean
  isOutdated?: boolean
  comments: { author: string; body: string; url: string }[]
}

export interface PastComment {
  path: string
  body: string
  diff_hunk: string
  html_url: string
  user: { login: string; type: string }
}

const minutesAgo = (minutes: number) => new Date(Date.now() - minutes * 60_000).toISOString()

export function signedIn(gh: Gh): void {
  gh.set('user', { stdout: `${REVIEWER}\n` })
  gh.set('review-requests', json([]))
}

export function signedOut(gh: Gh): void {
  gh.set('user', failure('To get started with GitHub CLI, please run:  gh auth login'))
}

export function reviewRequests(gh: Gh, prs: FixturePr[]): void {
  gh.set(
    'review-requests',
    json(
      prs.map((pr) => ({
        number: pr.number,
        title: pr.title,
        url: pr.url,
        isDraft: false,
        updatedAt: minutesAgo(5),
        author: { login: 'alice' },
        repository: { nameWithOwner: slug(pr) },
      })),
    ),
  )
}

export function stackEntry(pr: FixturePr) {
  return {
    number: pr.number,
    title: pr.title,
    url: pr.url,
    headRefName: pr.headRefName,
    baseRefName: pr.baseRefName,
    isCrossRepository: false,
  }
}

export function prView(pr: FixturePr) {
  return {
    number: pr.number,
    url: pr.url,
    title: pr.title,
    body: pr.body,
    author: { login: 'alice' },
    state: 'OPEN',
    isDraft: false,
    baseRefName: pr.baseRefName,
    headRefName: pr.headRefName,
    baseRefOid: pr.baseSha,
    headRefOid: pr.headSha,
    additions: pr.additions,
    deletions: pr.deletions,
    changedFiles: pr.changedFiles,
    closingIssuesReferences: [],
  }
}

/** Scripts everything opening `pr` asks GitHub for: no stack, no threads, no past review comments. */
export function pullRequest(gh: Gh, pr: FixturePr): void {
  gh.set(`pr ${key(pr)}`, json(prView(pr)))
  gh.set(`stack ${key(pr)}`, json({ data: { repository: { pullRequest: { stack: null } } } }))
  gh.set(`open-prs ${slug(pr)}`, json([stackEntry(pr)]))
  threads(gh, pr, [])
  pastReviewComments(gh, pr, [])
}

export function threads(gh: Gh, pr: FixturePr, fixtures: ThreadFixture[]): void {
  const nodes = fixtures.map((thread, threadIndex) => ({
    id: thread.id,
    path: thread.path,
    line: thread.line,
    startLine: thread.startLine ?? null,
    diffSide: thread.diffSide ?? 'RIGHT',
    subjectType: 'LINE',
    isResolved: thread.isResolved ?? false,
    isOutdated: thread.isOutdated ?? false,
    comments: {
      nodes: thread.comments.map((comment, index) => ({
        author: { login: comment.author },
        body: comment.body,
        createdAt: minutesAgo(60 * (threadIndex + 1) - index),
        url: comment.url,
      })),
    },
  }))
  gh.set(`threads ${key(pr)}`, json([{ data: { repository: { pullRequest: { reviewThreads: { nodes } } } } }]))
}

/** The app reads three pages; `comments` fills the first and the rest stay empty. */
export function pastReviewComments(gh: Gh, pr: FixturePr, comments: PastComment[]): void {
  gh.set(`review-comments ${slug(pr)} page 1`, json(comments))
  gh.set(`review-comments ${slug(pr)} page 2`, json([]))
  gh.set(`review-comments ${slug(pr)} page 3`, json([]))
}

export function reviewAccepted(gh: Gh, pr: FixturePr, reviewId = 1): string {
  const url = `${pr.url}#pullrequestreview-${reviewId}`
  gh.set(`submit ${key(pr)}`, json({ html_url: url }))
  return url
}
```

```ts
import { type ElectronApplication, type Page, _electron, test as base, expect } from '@playwright/test'
import { Gh } from '../harness/gh'
import type { ProviderId } from '../../src/shared/types'
import { BIN, type Run, SEED_SETTINGS, appArgs, appEnv, prepareRun, runPaths } from '../harness/launcher'
import { type Mock, startMock } from '../harness/mock-api'
import { ELECTRON, MANIFEST } from '../harness/paths'
import { type Manifest, readManifest } from '../harness/remotes'
import { pullRequest, signedIn } from '../harness/world'

/** The home screen loads reviewer avatars from GitHub; the proxy refuses them like everything else. */
const RENDERER_HOSTS = ['avatars.githubusercontent.com:443']

export interface Dojo {
  run: Run
  gh: Gh
  mock: Mock
  prs: Manifest['prs']
  /** Starts the app on this test's run directory; call it again after `close()` to relaunch. */
  launch(): Promise<Page>
  close(): Promise<void>
  openedLinks(): string[]
}

export const test = base.extend<{ dojo: Dojo; provider: ProviderId }>({
  provider: ['claude', { option: true }],

  dojo: async ({ provider }, use, testInfo) => {
    const manifest = readManifest(MANIFEST)
    const dir = testInfo.outputPath('run')
    const mock = await startMock(runPaths(dir).mockLog)
    const run = prepareRun(dir, mock.url, { ...SEED_SETTINGS, provider })
    const gh = new Gh(run.ghScript, run.ghLog)
    signedIn(gh)
    pullRequest(gh, manifest.prs.widget)

    let app = null as ElectronApplication | null
    let page = null as Page | null
    const pageErrors: string[] = []

    const close = async () => {
      if (!app) return
      const closing = app
      app = null
      await closing.context().tracing.stop({ path: testInfo.outputPath(`trace-${Date.now()}.zip`) })
      await closing.close()
    }

    const launch = async () => {
      await close()
      app = await _electron.launch({
        executablePath: ELECTRON,
        args: appArgs(run, mock.url),
        env: appEnv(run, mock.url, manifest.remotes),
      })
      await app.context().tracing.start({ screenshots: true, snapshots: true })
      page = await app.firstWindow()
      page.on('pageerror', (error) => pageErrors.push(error.message))
      const path = await app.evaluate(() => process.env.PATH ?? '')
      if (path.split(':')[0] !== BIN) throw new Error(`The fake gh is not first on the app's PATH: ${path}`)
      return page
    }

    await use({
      run,
      gh,
      mock,
      prs: manifest.prs,
      launch,
      close,
      openedLinks: () => (existsSync(run.openLog) ? readFileSync(run.openLog, 'utf8').split('\n').filter(Boolean) : []),
    })

    if (testInfo.status !== testInfo.expectedStatus) {
      await page?.screenshot({ path: testInfo.outputPath('failure.png') }).catch(() => undefined)
    }
    await close()
    await mock.close()
    expect
      .soft(
        gh.unscripted().map((call) => `gh ${call.argv.join(' ')}`),
        'gh calls nobody scripted',
      )
      .toEqual([])
    expect.soft(pageErrors, 'uncaught errors in the renderer').toEqual([])
    expect.soft(mock.unexpected, 'model API requests the mock did not expect').toEqual([])
    expect.soft(mock.pending(), 'scripted model turns nobody consumed').toBe(0)
    expect
      .soft(
        mock.blocked.filter((target) => !RENDERER_HOSTS.includes(target)),
        'connections attempted beyond loopback',
      )
      .toEqual([])
  },
})

export { expect }
```

```ts
import { type Locator, expect } from '@playwright/test'

export type LineKind = 'addition' | 'deletion' | 'context' | 'expanded'

const LINE_TYPE: Record<LineKind, string> = {
  addition: 'change-addition',
  deletion: 'change-deletion',
  context: 'context',
  expanded: 'context-expanded',
}

const codeLine = (scope: Locator, kind: LineKind, line: number): Locator =>
  scope.locator(`[data-content] [data-line-type="${LINE_TYPE[kind]}"][data-line="${line}"]`)

const lineNumber = (scope: Locator, kind: LineKind, line: number): Locator =>
  scope.locator(`[data-gutter] [data-line-type="${LINE_TYPE[kind]}"][data-column-number="${line}"]`)

/** The composer's and the draft editor's text field; their forms carry "comment" in their own names. */
export const commentBox = (scope: Locator): Locator => scope.getByRole('textbox', { name: 'Comment', exact: true })

/** The rendered code of every diff inside `scope`, for text assertions. */
export const diffCode = (scope: Locator): Locator => scope.locator('[data-content]')

/**
 * The "+" exists only while a line is hovered, and a diff that re-renders (highlighting landing, a
 * neighbour mounting) drops it until the pointer moves again, so the hover is repeated with the click.
 */
export async function startComment(scope: Locator, kind: LineKind, line: number): Promise<void> {
  await expect(async () => {
    await scope.page().mouse.move(0, 0)
    await codeLine(scope, kind, line).hover()
    await scope.locator('[data-utility-button]').click({ timeout: 1000 })
  }).toPass()
}

export async function selectLines(scope: Locator, kind: LineKind, from: number, to: number): Promise<void> {
  const mouse = scope.page().mouse
  await lineNumber(scope, kind, from).hover()
  await mouse.down()
  await lineNumber(scope, kind, to).hover()
  await mouse.up()
}

export async function expandContextBetweenHunks(scope: Locator): Promise<void> {
  await scope.locator('[data-gutter] [data-expand-button][data-expand-both]').click()
}
```

```ts
import type { Chapter, Stop, Tour } from '../../src/shared/types'
import type { FixturePr } from './remotes'

/** What a model returns: a tour before the app has given its chapters and stops their ids. */
export type ScriptedStop = Omit<Stop, 'id'>
export type ScriptedChapter = Omit<Chapter, 'id' | 'stops'> & { stops: ScriptedStop[] }
export type ScriptedTour = Omit<Tour, 'chapters'> & { chapters: ScriptedChapter[] }

export function stop(title: string, hunkIds: string[], extra: Partial<ScriptedStop> = {}): ScriptedStop {
  return {
    title,
    hunkIds,
    explanation: `${title}: what changed and why.`,
    risk: 'low',
    riskReason: 'Small and local.',
    checks: [],
    context: [],
    conventions: [],
    question: null,
    ...extra,
  }
}

/** Three stops over the four hunks of acme/widget#7, in tour order: greeting, farewell, double. */
export function widgetTour(
  pr: FixturePr,
  summary = 'Greetings gain an exclamation mark and a farewell.',
): ScriptedTour {
  return {
    summary,
    intent: {
      stated: ['Add an exclamation mark to greetings', 'Add a farewell helper'],
      claims: [
        { claim: 'Greetings end with an exclamation mark', status: 'delivered', evidence: 'See `src/greet.ts:3`.' },
      ],
      unexplained: [{ description: 'A `double` helper nobody asked for.', hunkIds: pr.hunks['src/util/math.ts'] }],
    },
    chapters: [
      {
        title: 'Greeting',
        goal: 'How a greeting is built.',
        stops: [
          stop('Friendlier greeting', pr.hunks['src/greet.ts'], {
            explanation: 'The greeting now ends with an exclamation mark. Compare `src/util/math.ts:2`.',
```

```ts
import { type ChildProcess, spawn } from 'node:child_process'
import { existsSync, readFileSync, rmSync, writeFileSync } from 'node:fs'
import http from 'node:http'
import type { AddressInfo } from 'node:net'
import { join, resolve } from 'node:path'
import { chromium, expect } from '@playwright/test'
import * as diff from '../support/diff'
import * as review from '../support/review'
import { Gh, type GhReply } from './gh'
import { appArgs, appEnv, prepareRun, runPaths } from './launcher'
import { type Turn, startMock } from './mock-api'
import { ARTIFACTS, ELECTRON, MANIFEST } from './paths'
import { buildFixtures, readManifest } from './remotes'
import { pullRequest, signedIn } from './world'

interface Session {
  hostPid: number
  cdpPort: number
  controlPort: number
}

const USAGE = `usage: npm run e2e:app -- <command> <run-dir> [argument]

  start <run-dir>             launch the built app with every stand-in; prints the session
  step  <run-dir> '<js>'      run an async function body with page, expect, diff and review in scope
  turns <run-dir> '<json>'    queue model turns: a JSON array of mock-api Turn objects
  gh    <run-dir> <route> '<json>'   set the fake gh reply for a route: {"stdout","stderr","exit","delayMs"}
  state <run-dir>             print what reached the boundaries and what the stand-ins refused
  stop  <run-dir>             quit the app and its stand-ins`

const sessionPath = (dir: string) => join(dir, 'session.json')

function readSession(dir: string): Session {
  if (!existsSync(sessionPath(dir))) throw new Error(`No app is running for ${dir}. Start one with: start ${dir}`)
  return JSON.parse(readFileSync(sessionPath(dir), 'utf8')) as Session
}

async function waitFor<T>(what: string, read: () => T | null | undefined, timeoutMs = 20_000): Promise<T> {
  const deadline = Date.now() + timeoutMs
  for (;;) {
    const value = read()
    if (value !== null && value !== undefined) return value
    if (Date.now() > deadline) throw new Error(`Timed out waiting for ${what}`)
    await new Promise((done) => setTimeout(done, 50))
  }
}

async function control(dir: string, path: string, body?: string): Promise<string> {
  const { controlPort } = readSession(dir)
  const response = await fetch(
    `http://127.0.0.1:${controlPort}${path}`,
    body === undefined ? {} : { method: 'POST', body },
  )
  if (!response.ok) throw new Error(await response.text())
  return response.text()
}

async function host(dir: string): Promise<void> {
  const manifest = existsSync(MANIFEST) ? readManifest(MANIFEST) : buildFixtures(ARTIFACTS)
  const mock = await startMock(runPaths(dir).mockLog)
  const run = prepareRun(dir, mock.url)
  const gh = new Gh(run.ghScript, run.ghLog)
  signedIn(gh)
  pullRequest(gh, manifest.prs.widget)

  const app: ChildProcess = spawn(ELECTRON, [...appArgs(run, mock.url), '--remote-debugging-port=0'], {
    env: appEnv(run, mock.url, manifest.remotes),
    stdio: 'ignore',
  })
  const portFile = join(run.userData, 'DevToolsActivePort')
  rmSync(portFile, { force: true })
  const cdpPort = await waitFor('the app to open its debugging port', () =>
    existsSync(portFile) ? Number(readFileSync(portFile, 'utf8').split('\n')[0]) : null,
  )

  const server = http.createServer((request, response) => {
    let body = ''
    request.on('data', (chunk) => (body += chunk))
    request.on('end', () => {
      if (request.url === '/turns') mock.script(...(JSON.parse(body) as Turn[]))
      else if (request.url === '/release') mock.release(body)
      response.end(JSON.stringify({ unexpected: mock.unexpected, blocked: mock.blocked, pendingTurns: mock.pending() }))
    })
  })
  await new Promise<void>((done) => server.listen(0, '127.0.0.1', done))
  const session: Session = { hostPid: process.pid, cdpPort, controlPort: (server.address() as AddressInfo).port }
  writeFileSync(sessionPath(dir), JSON.stringify(session))

  const shutdown = () => {
    rmSync(sessionPath(dir), { force: true })
    app.kill()
    process.exit(0)
  }
  app.on('exit', shutdown)
  process.on('SIGTERM', shutdown)
}

async function start(dir: string): Promise<void> {
  if (existsSync(sessionPath(dir))) throw new Error(`An app is already running for ${dir}. Stop it first.`)
  const child = spawn(process.execPath, [...process.execArgv, import.meta.filename, 'host', dir], {
    detached: true,
    stdio: 'ignore',
  })
  child.unref()
  const session = await waitFor('the app to start', () => (existsSync(sessionPath(dir)) ? readSession(dir) : null))
  console.log(JSON.stringify({ ...session, runDir: dir }))
}

async function step(dir: string, body: string): Promise<void> {
  const browser = await chromium.connectOverCDP(`http://127.0.0.1:${readSession(dir).cdpPort}`)
  try {
    const page = browser.contexts()[0].pages()[0]
    page.setDefaultTimeout(5000)
    const AsyncFunction = Object.getPrototypeOf(async () => undefined).constructor as new (
      ...parameters: string[]
    ) => (...values: unknown[]) => Promise<unknown>
    const result = await new AsyncFunction('page', 'expect', 'diff', 'review', body)(page, expect, diff, review)
    if (result !== undefined) console.log(typeof result === 'string' ? result : JSON.stringify(result, null, 2))
  } finally {
    await browser.close()
  }
}

async function state(dir: string): Promise<void> {
  const run = runPaths(dir)
  const gh = new Gh(run.ghScript, run.ghLog)
  console.log(
    JSON.stringify(
      {
        ...(JSON.parse(await control(dir, '/state')) as object),
        ghCalls: gh.calls().map((call) => ({ route: call.route, exit: call.exit, stdin: call.stdin })),
        ghUnscripted: gh.unscripted().map((call) => call.argv.join(' ')),
        openedLinks: existsSync(run.openLog) ? readFileSync(run.openLog, 'utf8').split('\n').filter(Boolean) : [],
      },
      null,
      2,
    ),
  )
}

async function main(): Promise<void> {
  const [command, dirArgument, ...rest] = process.argv.slice(2)
  if (!command || !dirArgument) throw new Error(USAGE)
  const dir = resolve(dirArgument)
  if (command === 'host') await host(dir)
  else if (command === 'start') await start(dir)
  else if (command === 'step') await step(dir, rest[0] ?? '')
  else if (command === 'turns') console.log(await control(dir, '/turns', rest[0]))
  else if (command === 'release') console.log(await control(dir, '/release', rest[0] ?? ''))
  else if (command === 'gh')
    new Gh(runPaths(dir).ghScript, runPaths(dir).ghLog).set(rest[0], JSON.parse(rest[1]) as GhReply)
  else if (command === 'state') await state(dir)
  else if (command === 'stop') process.kill(readSession(dir).hostPid, 'SIGTERM')
  else throw new Error(USAGE)
}

main().catch((error: unknown) => {
  console.error(error instanceof Error ? error.message.split('\n').slice(0, 8).join('\n') : error)
  process.exit(1)
})
```

```ts
import { execFileSync, spawn } from 'node:child_process'

const SAMPLE_MS = 200
const LOOPBACK = /^(127\.0\.0\.1|\[::1\]|localhost):/

function descendants(root: number): number[] {
  const rows = execFileSync('ps', ['-axo', 'pid=,ppid='], { encoding: 'utf8' })
    .trim()
    .split('\n')
    .map((row) => row.trim().split(/\s+/).map(Number))
  const found: number[] = []
  const visit = (pid: number) => {
    for (const [child, parent] of rows) {
      if (parent !== pid) continue
      found.push(child)
      visit(child)
    }
  }
  visit(root)
  return found
}

function remoteEnds(pids: number[]): string[] {
  if (pids.length === 0) return []
  let listing = ''
  try {
    listing = execFileSync('lsof', ['-nP', '-iTCP', '-a', '-p', pids.join(',')], { encoding: 'utf8' })
  } catch (error) {
    // lsof exits 1 when a listed process has no sockets or has already gone; what it printed still counts.
    listing = String((error as { stdout?: string }).stdout ?? '')
  }
  return listing
    .split('\n')
    .map((line) => /^(\S+)\s.*->(\S+)/.exec(line))
    .filter((match) => match !== null && !LOOPBACK.test(match[2]))
    .map((match) => `${match![1]} -> ${match![2]}`)
}

const [command, ...args] = process.argv.slice(2)
if (!command) {
  console.error('usage: tsx e2e/harness/outbound-watch.ts <command> [arguments]')
  process.exit(2)
}

const child = spawn(command, args, { stdio: 'inherit' })
const seen = new Set<string>()
let samples = 0
const timer = setInterval(() => {
  samples += 1
  for (const end of remoteEnds(descendants(child.pid!))) seen.add(end)
}, SAMPLE_MS)

child.on('exit', (code) => {
  clearInterval(timer)
  console.log(`outbound-watch: ${samples} samples, ${seen.size} connections beyond loopback`)
  for (const end of seen) console.log(`  ${end}`)
  process.exit(code !== 0 ? (code ?? 1) : seen.size > 0 ? 1 : 0)
})
```

## Concerns

The spec is followed throughout. These are the places where the plan's reading of it, or a limit of the
approach, should be seen by whoever approves the result.

1. **The gutter "+" keeps no accessible name.** The spec asks for one "if the diff library exposes a way". It
   does (`renderGutterUtility`), but only by giving up `onGutterUtilityClick`, which the app uses for click and
   drag from the gutter; combining them throws and blanks the diff. The plan takes the spec's fallback (one
   helper owns the shadow-DOM selectors). Naming the button would be a product change to the diff interaction
   and belongs in its own ticket.
2. **The "+" is fragile to drive.** Without a retry the helper failed 2 of 7 runs under four workers, because a
   re-rendering diff drops the hover-only button. The retry in `startComment` made it 44 of 44. If it flakes
   again, the durable fix is concern 1.
3. **The tripwire is not a firewall.** A process that ignores proxy variables could still connect out. The
   `outbound-watch` sampler in Task 10 is independent evidence, but it samples every 200 ms and follows child
   processes by parent id, so a very short connection or a re-parented process could be missed.
   `sandbox-exec` is ruled out by the spec for good reason.
4. **Route keys do not pin `--json` field lists.** The fake `gh` checks the shape of each call but accepts any
   field list after `--json`; a dropped field would show up only if a test asserts on what that field feeds.
   The full arguments are in the log for any test that wants to assert them.
5. **Fixture replies encode assumptions about real `gh`** (`--jq`, `--paginate --slurp`, field names). The spec
   puts checking them against live GitHub out of scope; the risk stays.
6. **The copy test stubs `navigator.clipboard.writeText`.** That is a stand-in inside the renderer rather than
   at a process boundary. The real call cannot succeed in an unfocused window, and the real clipboard is shared
   with the developer, so the alternative is no test.
7. **The settings test runs the bundled `codex login status`** (subscription sign-in for Codex) against an empty
   per-test `CODEX_HOME`. Observed: no connection attempt. Claude's subscription mode is deliberately not
   exercised, since its CLI may read the login keychain.
8. **Both wire formats, the Codex feature-flag names and the session header names are tied to the pinned CLI
   versions** (claude-agent-sdk 0.3.x, codex 0.157.1). An SDK bump can break the suite with no app change; the
   failure will name an unexpected request or blocked host.
9. **The focus hook uses the `prohibited` activation policy during launch.** It gave zero focus samples in two
   full runs here, against roughly 9% with the spike's hook, but it is macOS behaviour observed, not documented.
10. **Each Claude cancel test costs about 5 s** (the SDK waits 2 s before stopping its CLI), and the whole suite
    about a minute on four workers.
11. **The fake `gh` needs Node 22.6 or newer** for type stripping; the README says Node 22+.
12. **Activity logs are named by their label, and one label changes** ("Thinking" becomes "Writing" once an
    answer streams), so the Ask cancel test locates Cancel through the panel rather than the group name.
